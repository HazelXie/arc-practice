# ARC Practice (Grade 4)

A small, no-install website where a 4th grader reads a short passage and writes an **ARC** answer:

- **A**nswer the question in a full sentence
- **R**eference the text (explain in your own words)
- **C**ite exact words from the passage

Runs in any browser, including iPad Safari. No accounts, no tracking. Progress (stars) is saved only on the device being used.

## Publish on GitHub Pages (works on iPad)

1. On github.com click **New repository**, name it `arc-practice`, keep it Public, create it.
2. Click **uploading an existing file**, drag in everything from this folder (`index.html`, `style.css`, `app.js`, `passages.js`, `README.md`), then **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
4. After about a minute the site is live at `https://YOUR-USERNAME.github.io/arc-practice/`.
5. On the iPad open that link in Safari, tap **Share → Add to Home Screen** to get an app-style icon.

## Add more passages

Open `passages.js` and copy one passage block. Change the title, text, questions and sample answers. No other file needs to change.
